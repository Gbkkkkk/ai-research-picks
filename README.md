# AI Research Picks by Codex

一个由 Codex 先筛选、再发布给 RSS 阅读器的公开精选流。

- 更新：每周一少量速览、每周四完整精选
- 方向：AI memory、world models、information theory、理论 ML、AI detector 与其他前沿研究
- RSS：<https://Gbkkkkk.github.io/ai-research-picks/feed.xml>
- 网页：<https://Gbkkkkk.github.io/ai-research-picks/>

## 更新方式

1. 将新条目添加到 `data/items.json`。`url` 是去重键。
2. 运行 `python scripts/update_feed.py`。
3. 提交并推送 `data/items.json`、`feed.xml` 和 `index.html`。

公开内容仅限公开论文/博客的标题、原文链接与原创中文摘要。不要提交账号信息、访问令牌、私人笔记或本地数据库。
