On the Information Bottleneck Theory of Deep Learning

检验将普通深度网络训练解释成“先拟合、后压缩”的信息瓶颈叙事，指出压缩阶段与激活函数、互信息估计方式密切相关，不能当作普遍规律。

为什么值得读：你刚读完原始 IB 方法，接着读这篇能把“IB 是有用目标”与“SGD 必然实现 IB 压缩”清楚地区分。

阅读提示：它反驳的是特定的深度学习动力学解释，不否定 IB 作为表征学习目标；论文也依赖所考察模型与估计设定。

On Variational Bounds of Mutual Information

在统一框架里比较神经互信息估计的多种变分下界，分析高互信息区域的偏差—方差问题，并给出可调折中的连续下界族。

为什么值得读：读 Deep VIB 或用互信息做实验时，必须知道优化的是哪个界、估计误差如何影响结论；这篇是实操与理论之间的桥梁。

阅读提示：论文聚焦特定变分下界与受控高维实验，不能保证在任意真实表征或极高维连续变量上都能准确估计互信息。

A Watermark for Large Language Models

通过对随机选出的绿色 token 集在采样时施加轻微偏置，在生成文本里嵌入可统计检测的信号；给出带可解释 p 值的检测检验与灵敏度分析。

Lost in the Middle: How Language Models Use Long Contexts

通过多文档问答和键值检索，系统改变关键证据在长上下文中的位置；许多模型在开头或末尾表现较好，证据位于中段时性能明显下降。

阅读提示：结论来自当时的模型与任务；后续长上下文模型可能改善特定设置，位置效应需要按新模型重新测量。

IMPLY: Physically Anchored Consistency for World-Model Rollouts

指出多个 rollout 相互一致并不代表符合真实对象：一个总预测典型推动结果的模型也能自洽。IMPLY 用少量校准推力作为外部锚点，反推质量与摩擦并检验预测是否与同一物体相符。

为什么值得读：世界模型需要的是对真实物理状态有约束的可靠预测，而不仅是流畅、内部自洽的未来视频；这篇把评价问题说得很尖锐。

阅读提示：仅为 7 页预印本，验证集中于推物体场景且需要可用的物理反演与校准动作；跨物体、复杂接触和开放场景适用性待证。

Efficient Robust Learning at the Information-Theoretic Limit

把固定分布下的鲁棒学习从已知但计算低效的最优误差率推进到多项式时间：借助 ERM oracle 与 no-regret 学习，实现随机化分类器的 η+ε 误差。

为什么值得读：这是理论 ML 中很干净的“统计最优能否兼得计算效率”问题，且给出高斯边际下半空间学习的具体结果。

阅读提示：保证依赖固定分布、噪声模型和 oracle 等前提；不应外推到任意非平稳数据或开放式大模型鲁棒性。

Memory Networks

为什么值得读：这是现代神经记忆与检索增强系统的重要源头之一。它最值得借鉴的不是具体打分函数，而是把“模型参数中的知识”和“运行时可更新的记忆”明确分开。

Generative Agents: Interactive Simulacra of Human Behavior

给 LLM agent 配置自然语言记忆流，以相关性、新近性和重要性检索经历，再周期性生成高层反思并据此规划行为；25 个 agent 的沙盒展示了由局部记忆产生的社会互动。

阅读提示：核心评估以小规模沙盒中的“行为可信度”为主，受提示、基础模型和人工评价影响；它展示的是设计范式，不是对长期可靠性或真实人类行为的证明。

Mastering Atari, Go, Chess and Shogi by Planning with a Learned Model

MuZero 不重建完整观测，而是学习对规划足够的隐状态动力学，直接预测奖励、策略与价值，并与树搜索联合训练；在棋类与 57 个 Atari 游戏上展示统一能力。

为什么值得读：它提供了一个关键世界模型观点：模型不必像素级模拟世界，只需保留决策相关的可预测结构。这个观点对 latent world model、agent planning 与表征学习都很重要。

阅读提示：训练与搜索计算量很大，基准环境边界清晰且反馈密集；在开放世界、部分可观测和语言交互任务中，学到的隐状态是否忠实且可迁移仍是额外问题。

Memory as Plans: World-Action Modeling with Memory-Grounded Planning

The Information Bottleneck Method

把“学到一个好表征”写成明确的率失真式优化：尽量压缩输入 X，同时保留对目标 Y 有用的互信息。它给出自洽方程与可收敛的重估算法，是信息论进入表征学习讨论的核心起点。

为什么值得读：你关注 information theory 与理论 ML，这篇提供了一个可反复复用的语言：相关信息、最小充分表征、压缩—预测权衡。后来的 VIB、β-VAE、表征压缩争论都能沿这条线读。

阅读提示：经典框架不等于深网训练动力学的完整解释；互信息在连续确定性网络中还会遇到估计与定义上的技术问题。

必读 · 论文 · 2018-03-27 · world models · model-based RL · latent dynamics

World Models

用 VAE 压缩视觉观测、RNN 学习潜在动力学，再在模型产生的“梦境”里训练小型控制器。它以极简而完整的系统展示：预测性表征本身可以成为决策的训练环境。

为什么值得读：不是最强的现代算法，却是 world model 研究最清楚的概念入口之一；模块划分、latent imagination 与 sim-to-real 风险至今仍是主线。

阅读提示：实验环境较简单，模型误差会被策略利用；不要把“在梦里训练成功”直接外推到复杂开放世界。
