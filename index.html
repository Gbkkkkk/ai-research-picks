LLMs Get Lost In Multi-Turn Conversation

为什么值得读：为 agent memory 和对话评测提供清晰的失效定义；写法值得学习：固定最终可用信息，仅改变交互过程，再把总性能差分解为能力与可靠性。

阅读提示：主要证据来自模拟对话和论文测试的模型；39% 是任务平均值，不能外推为真实用户对话或所有新模型的统一跌幅。

Vision Transformers Need Registers

论文发现监督与自监督 ViT 的特征图会在信息量很低的背景区域出现高范数 token，像是被挪作内部计算的临时空间。加入专门的 register token 后，视觉特征与注意力图更平滑，并改善若干密集预测任务。

为什么值得读：这是学习机制型论文写法的好材料：先用可视化和统计定位异常，再给最小结构改动，最后验证异常是否消失及任务指标是否改善。它也让我们跳出只读语言模型的视角。

阅读提示：register 的作用和收益取决于模型、训练方式及下游任务；不能把该实验现象外推成所有视觉 Transformer 都需要同一数量或形式的额外 token。

Transformers are Inherently Succinct

为什么值得读：值得学习它如何更换理论问题的量尺：从可表达性转向简洁性，并把优势与验证代价放在同一框架里。ICLR 2026 将其列为杰出论文。

阅读提示：结论是固定精度、形式语言与存在性构造下的复杂性结果，不直接预测现实 LLM 的准确率或可训练性；获奖委员会也注明该工作存在争议。

Proving Test Set Contamination in Black Box Language Models

阅读提示：方法依赖数据顺序具有可交换性且模型可能记住规范排列；无序集合、顺序本身带语义或经过特殊预处理的数据不一定适用，未拒绝零假设也不能证明绝对无污染。

把“学到一个好表征”写成明确的率失真式优化：尽量压缩输入 X，同时保留对目标 Y 有用的互信息。它给出自洽方程与可收敛的重估算法，是信息论进入表征学习讨论的核心起点。

为什么值得读：你关注 information theory 与理论 ML，这篇提供了一个可反复复用的语言：相关信息、最小充分表征、压缩—预测权衡。后来的 VIB、β-VAE、表征压缩争论都能沿这条线读。

阅读提示：经典框架不等于深网训练动力学的完整解释；互信息在连续确定性网络中还会遇到估计与定义上的技术问题。

World Models

为什么值得读：不是最强的现代算法，却是 world model 研究最清楚的概念入口之一；模块划分、latent imagination 与 sim-to-real 风险至今仍是主线。

阅读提示：实验环境较简单，模型误差会被策略利用；不要把“在梦里训练成功”直接外推到复杂开放世界。
