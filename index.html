必读 · 论文 · 2000-04-24（arXiv；工作源于 1999） · information theory · representation learning · compression

The Information Bottleneck Method

把“学到一个好表征”写成明确的率失真式优化：尽量压缩输入 X，同时保留对目标 Y 有用的互信息。它给出自洽方程与可收敛的重估算法，是信息论进入表征学习讨论的核心起点。

为什么值得读：你关注 information theory 与理论 ML，这篇提供了一个可反复复用的语言：相关信息、最小充分表征、压缩—预测权衡。后来的 VIB、β-VAE、表征压缩争论都能沿这条线读。

阅读提示：经典框架不等于深网训练动力学的完整解释；互信息在连续确定性网络中还会遇到估计与定义上的技术问题。

必读 · 论文 · 2018-03-27 · world models · model-based RL · latent dynamics

World Models

用 VAE 压缩视觉观测、RNN 学习潜在动力学，再在模型产生的“梦境”里训练小型控制器。它以极简而完整的系统展示：预测性表征本身可以成为决策的训练环境。

为什么值得读：不是最强的现代算法，却是 world model 研究最清楚的概念入口之一；模块划分、latent imagination 与 sim-to-real 风险至今仍是主线。

阅读提示：实验环境较简单，模型误差会被策略利用；不要把“在梦里训练成功”直接外推到复杂开放世界。

必读 · 论文 · 2014-10-20 · AI memory · external memory · differentiable computing

Neural Turing Machines

把神经网络控制器与可微分的外部记忆矩阵耦合，通过内容寻址和位置寻址进行读写，从而端到端学习复制、排序与联想回忆等算法行为。

为什么值得读：这是理解“模型参数之外的可操作记忆”最重要的早期原型；今天 agent memory、检索、读写策略和内存管理中的许多问题，在这里已有清晰雏形。

阅读提示：结果主要来自玩具算法任务，训练稳定性与规模扩展有限；它更适合作为机制原型，而非现代 LLM memory 的直接方案。

必读 · 论文 · 2016-11-10 · theoretical ML · generalization · optimization

Understanding Deep Learning Requires Rethinking Generalization

通过随机标签和随机像素实验表明，过参数化网络可以轻易记住无结构数据，传统的模型容量与显式正则化解释不足以说明深网为何泛化。论文还给出浅层网络有限样本表达能力的理论构造。

为什么值得读：它重置了现代泛化理论的问题定义：难点不是网络能否拟合，而是 SGD、数据结构与归纳偏置为何选择了能泛化的解。

阅读提示：论文主要提出反例与诊断，不提供统一的新泛化理论；随机标签设置与自然任务之间仍有距离。

必读 · 论文 · 2023-03-17（2025-01 修订） · AI detector · robustness · information theory

Can AI-Generated Text Be Reliably Detected?

系统压力测试分类器、零样本检测、检索与水印方案，展示递归改写可显著削弱检测率，并用总变差距离连接最优检测器的 AUROC 与人类/机器文本分布的可分性。

为什么值得读：做 AI detector 不能只追逐榜单；这篇把问题拉回到攻击者存在时的可靠性边界，是判断任何 detector claim 时最重要的反方基线。

阅读提示：结论针对文中攻击与分布假设，并非证明所有条件下检测都不可能；水印、来源证明和受控生成仍有不同威胁模型。

值得浏览 · 论文 · 2023-10-12 · AI memory · LLM agents · context management

MemGPT: Towards LLMs as Operating Systems

借鉴操作系统虚拟内存，把有限上下文视为快速内存，并在不同记忆层之间主动迁移信息；同时用中断机制管理 LLM 的控制流。论文在长文档分析与多会话对话中展示了这一设计。

为什么值得读：它把 agent memory 从“检索一些相似片段”推进为资源管理问题：何时写、写到哪层、何时换入上下文、谁控制这些动作。

阅读提示：系统结果依赖底层模型、提示与任务；论文中的实现已演化为后续产品/框架，读时应区分原始研究主张与后来的工程生态。

值得浏览 · 论文 · 2023-01-26 · AI detector · zero-shot detection · language models

DetectGPT: Zero-Shot Machine-Generated Text Detection Using Probability Curvature

提出基于概率曲率的零样本检测思想：模型生成文本倾向位于生成模型对数概率函数的负曲率区域，通过对文本做扰动并比较似然变化进行判断，无需训练单独分类器。

为什么值得读：它是 detector 领域少数具有鲜明机制假设的方法，适合用来学习如何从生成分布几何构造统计量，并与纯监督分类器区分。

阅读提示：需要访问相关模型的概率并执行多次扰动，计算成本较高；跨模型、改写攻击和分布漂移会削弱可靠性。

值得浏览 · 论文 · 2023-01-10（2024-04 修订） · world models · model-based RL · general agents

Mastering Diverse Domains through World Models (DreamerV3)

DreamerV3 用统一配置在 150 多个任务上训练世界模型并通过想象轨迹改进策略，关键在于归一化、平衡与变换等稳定化设计；还展示了从像素和稀疏奖励出发在 Minecraft 获取钻石。

为什么值得读：它展示 world model 从漂亮概念走向跨域通用算法时，真正决定成败的往往是目标尺度、优化稳定性与统一超参数，而不只是更复杂的生成模型。

阅读提示：广覆盖不等于真实开放世界泛化；结果仍依赖大量交互计算，而且论文主要是强化学习语境下的 world model。

值得浏览 · 论文 · 2020-01-23 · scaling laws · theoretical ML · language models

Scaling Laws for Neural Language Models

在跨越多个数量级的实验中发现语言模型交叉熵对模型规模、数据量与训练算力呈稳定幂律关系，并讨论固定计算预算下的资源分配。

为什么值得读：它深刻影响了前沿实验室如何规划训练与预测收益，也是理解“规模化为何成为研究策略”的必读背景。

阅读提示：这是经验规律而非第一性原理；后续 Chinchilla 等工作修正了计算最优的数据/参数配比，不能把原文配方当作最终结论。

值得浏览 · 论文 · 2016-12-01 · information theory · variational inference · representation learning

Deep Variational Information Bottleneck

用变分近似与重参数化技巧把信息瓶颈目标变成可由神经网络高效优化的下界，形成 Deep VIB，并研究其泛化与对抗鲁棒性。

为什么值得读：它是从原始信息瓶颈理论跨到现代深度学习实现的关键桥梁，能帮助你看懂大量带 KL 正则、压缩表征与不确定性的后续工作。

阅读提示：互信息项由变分界替代，效果受近似族和估计质量影响；论文中的鲁棒性结果不应视为普遍保证。

必读 · 博客 · 2019-03-13 · research taste · scaling · search and learning

The Bitter Lesson

Sutton 从 AI 史反复出现的模式提出判断：长期看，能随计算增长而扩展的通用搜索与学习方法，往往压过由研究者手工注入的领域结构。

为什么值得读：这不是一句“规模即一切”的口号，而是一把评估研究路线的尺子：你的方法是否能利用未来更多计算，还是很快被人工设计的上限卡住？

阅读提示：文章是研究品味与历史归纳，不是形式化定理；领域知识、数据效率、安全约束与计算成本仍可能决定现实最优方案。此链接为经许可重刊。

LLM Powered Autonomous Agents

以规划、记忆和工具使用为三大组件梳理 LLM agent，连接反思、自我改进、向量检索、长期记忆与外部工具等早期代表工作。

为什么值得读：虽然写于 agent 爆发早期，它仍是建立统一术语和文献地图的高密度入口，尤其适合从 memory 机制延伸到完整 agent loop。

阅读提示：领域发展很快，具体框架与性能判断已经过时一部分；应把它当作 2023 年的结构化快照，而不是当前 SOTA 清单。

Building Effective Agents

区分预定义工作流与自主 agent，并总结 prompt chaining、routing、parallelization、orchestrator-workers、evaluator-optimizer 等可组合模式；核心建议是从最简单可验证的结构开始。

值得浏览 · 博客 · 2015-08-27 · neural memory · RNN · long-term dependencies

Understanding LSTM Networks

用经典图解逐步解释 LSTM 的 cell state、遗忘门、输入门与输出门，说明门控如何缓解普通 RNN 的长期依赖学习问题。

为什么值得读：现代 agent memory 已远超 LSTM，但理解“状态如何选择性保留、写入和读取”仍是研究记忆机制的最低层直觉基础。

阅读提示：内容面向 2015 年的循环网络范式，不覆盖 Transformer、外部检索或多层 agent memory；价值主要在机制解释。
